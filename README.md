# ⚙️ SplitWise Clone - Backend

Backend service for the **SplitWise Clone** application built with **Spring Boot**. It provides secure authentication, REST APIs, real-time chat using WebSocket, email OTP verification, and MySQL database integration.

🌐 **Live Backend**

https://backend-splitwise.onrender.com

---

# ✨ Features

## 🔐 Authentication

- User Signup
- User Login
- JWT Authentication
- Password Encryption (BCrypt)
